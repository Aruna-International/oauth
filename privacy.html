Privacy Policy

666 Seconds — Channel Uploader · Last updated 26 September 2026

This application is my own private tool. I use it to publish my own videos to my own YouTube channels. I am its only user, it has no other users, and it offers no service to the public.

What data the application accesses

  • YouTube account access, which I grant myself through Google's OAuth consent screen, limited to uploading and managing videos on my own channels.
  • Video files, titles, descriptions, tags, captions and thumbnails that I create, which the application sends to YouTube on my behalf.
  • Video identifiers and upload status returned by YouTube, recorded on my own computer so the tool knows what it has already published.

What the application does not do

  • It does not access, read or modify any Google account other than my own, the one that grants consent.
  • It does not read my email, contacts, files or any other Google service.
  • It does not collect data from viewers of my channels.
  • It does not sell, rent or share any data with third parties.
  • It does not use any data for advertising or profiling.
  • It does not transfer data to any server other than Google's own APIs.

Where data is stored

The OAuth credentials issued by Google are stored only on my own computer, in a local file that is not shared, published or backed up to any third-party service. Video and metadata files are likewise kept on my own computer until they are uploaded to YouTube.

Retention

Credentials are kept only as long as I am using the tool, and are deleted when I revoke access or remove the tool. Local records of published video identifiers are kept for my own reference and contain no personal data about anyone else.

Revoking access

I can withdraw access at any time from Google Account permissions. Revoking immediately stops the application from being able to reach my account.

Google API Services User Data Policy

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Changes

If this policy changes, I will post the updated version on this page with a new date.
